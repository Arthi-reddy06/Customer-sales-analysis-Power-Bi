 Customer Sales Analysis Dashboard

 Project Overview
This project analyzes customer sales data using Microsoft Power BI to identify sales performance, profitability, regional trends, and category-level insights.

 Tools Used
- Microsoft Power BI
- Power Query
- DAX (if used in the project)

Key Performance Indicators
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Orders: 5,009

 Dashboard Features
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Category slicer for interactive filtering
- Sales and Profit comparison by Category

Key Learnings
- Cleaned and prepared data using Power Query.
- Created KPI cards and interactive visualizations.
- Analyzed sales, profit, and regional performance.
- Built a dashboard to communicate business insights.
